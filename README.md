# Personal Wall

A minimal full-stack blogging platform where users can publicly post messages in a clean endless feed.

Built using React, TypeScript, Bootstrap, Supabase, and Vercel.

---

## Features

- Public posting system
- Dynamic endless feed
- Persistent cloud database storage
- Password-protected delete moderation
- Responsive modern UI
- Full-stack deployment

---

## Tech Stack

- **React** — frontend component architecture
- **TypeScript** — type safety and scalability
- **Bootstrap** — responsive UI styling
- **Supabase** — backend database and API
- **Vercel** — deployment and hosting
- **Git & GitHub** — version control and workflow

---

## Skills & Concepts Learned

- React state management (`useState`, `useEffect`)
- Dynamic rendering with `.map()`
- Controlled forms and event handling
- CRUD operations with Supabase
- Async/await and API integration
- Frontend ↔ backend communication
- Database persistence and cloud storage
- Git workflows and deployment pipelines
- Debugging real-world integration issues

---

## Challenges Faced

- Handling Supabase RLS and database permissions
- Fixing incorrect API key usage
- Debugging frontend/backend data flow
- Resolving Git merge conflicts
- Managing persistent online data correctly

---

## Deployment

Frontend deployed on Vercel with Supabase used as the cloud backend and database.
